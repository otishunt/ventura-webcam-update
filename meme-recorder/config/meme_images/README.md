Put one reference image per meme in this folder, using the filenames listed
under `image:` in `config/memes.yaml` (for example `side_eye.jpg` or
`breaking_free.jpg`).

Images are not included in this repo. Download the meme templates yourself
and record where each one came from (for example its Know Your Meme page) in
`SOURCES.md` in this folder so your report can cite them. If an image is
missing, participants see the text instruction only.

Consider not using the "Side-Eye Chloe" image, because it shows a young
child. A different side-eye reference, or a photo of a team member doing the
pose, works just as well.
